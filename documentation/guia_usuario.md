# Guía de Usuario - HUD Creator

## Instalación
1. Crea un prim en SL
2. Copia todos los scripts .lsl al prim
3. Configura en config.lsl
4. Adjunta como HUD

## Comandos
- `/hud menu` - Menú principal
- `/hud textures` - Gestor de texturas
- `/hud pbr` - Materiales PBR
- `/hud sounds` - Sonidos
- `/hud animations` - Animaciones
- `/hud color` - Color

## Uso
1. Haz click en el HUD para abrir menú
2. Selecciona opción deseada
3. Sigue las instrucciones en pantalla
