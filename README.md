# Second Life HUD Creator

Un sistema completo para crear HUDs personalizados en Second Life con soporte para texturas, materiales PBR, sonidos, animaciones, colores y modos alpha.

## 🚀 Características

- Gestión de texturas para prims y mesh
- Materiales PBR completos
- Sistema de sonidos 3D
- Control de animaciones
- Color y transparencia
- E-commerce: cupones, pagos, inventario
- Integración con base de datos
- Sincronización web
- Sistema de reseñas
- Especialización para ropa

## 📋 Requisitos

- Second Life Viewer
- Conocimientos básicos de SL

## 🛠️ Instalación

1. Crea un prim en SL
2. Copia todos los scripts `.lsl` al prim
3. Configura según necesidad
4. Adjunta como HUD
